# Як отримати S.A.D.exe через GitHub (без командного рядка)

Усе робиться в браузері. Знадобиться безкоштовний обліковий запис на github.com.

## 1. Створіть репозиторій
1. github.com → кнопка **New** (або «+» угорі → *New repository*).
2. Назва, наприклад, `SAD`. Видимість: **Public** (безкоштовні хвилини збірки без обмежень) або **Private** (хвилини Windows-збірки
   рахуються подвійно, безкоштовний ліміт 2000 хв/міс. – одна збірка забирає приблизно 30–40 хв квоти).
3. Позначку «Add a README» **не ставте**. Натисніть *Create repository*.

## 2. Завантажте файли
1. Розпакуйте архів `SAD-repo.zip` у будь-яку теку на комп'ютері. У ній мають бути `main.py`, багато `sad_*.py`, `SAD.spec`, `installer.iss`,
   `requirements-build.txt` і тека **`.github`** (якщо її не видно – увімкніть показ прихованих файлів: у Windows *Вигляд → Показати → Приховані елементи*,
   у macOS *Cmd + Shift + .*).
2. На сторінці порожнього репозиторію натисніть **uploading an existing file**, виділіть **усе вміст розпакованої теки** (файли й теку `.github`)
   і перетягніть у вікно браузера. Дочекайтеся завантаження → внизу *Commit changes*.
3. **Перевірте**, що в репозиторії з'явився шлях `.github/workflows/build-windows.yml`. Якщо тека `.github` не завантажилась (так буває при
   перетягуванні): *Add file → Create new file*, у полі імені введіть `.github/workflows/build-windows.yml` (скісні риски створять теки), вставте вміст
   файлу `build-windows.yml` з архіву й натисніть *Commit changes*.
4. Якщо маєте `icon.ico` (іконка програми) та/або `Logo.png` – додайте їх у корінь так само (необов'язково).

## 3. Запустіть збірку
1. Вкладка **Actions** → ліворуч «Збірка Windows (.exe)» → праворуч **Run workflow** → зелена кнопка *Run workflow*.
   (Якщо GitHub просить дозволити Actions – натисніть *I understand my workflows, go ahead and enable them*.)
2. Збірка триває приблизно 10–25 хв (тести ≈ 5–8 хв, збірка й самоперевірка ≈ 5 хв). Щоб прискорити, при запуску зніміть прапорець тестів.
3. Коли біля запуску з'явиться зелена позначка – відкрийте його й унизу в розділі **Artifacts** завантажте **SAD-windows-zip** (програма)
   і, якщо є, **SAD-windows-installer** (інсталятор).

## 4. Користування
- З zip: розпакуйте й запустіть **SAD.exe** (всередині теки `SAD`; не переносьте `.exe` окремо від теки `_internal`).
- Інсталятор: запустіть `SAD-Setup-….exe` – він ставить програму для поточного користувача без прав адміністратора.
- Перший запуск Windows може показати «Невідомий видавець» (програма не підписана цифровим підписом): *Докладніше → Все одно запустити*.

## Випуск версії (необов'язково)
Release → *Draft a new release* → у полі *tag* введіть `v2.1.0` (*Create new tag*) → *Publish release*. Збірка запуститься сама, а zip та інсталятор
з'являться прямо на сторінці релізу.

## Якщо збірка не пройшла
Відкрийте запуск із червоною позначкою й подивіться, який крок червоний:
- **«Тести»** – запустіть збірку знову, але зніміть прапорець тестів, щоб отримати `.exe`; надішліть мені текст помилки.
- **«Самоперевірка зібраної програми»** – у журналі (артефакт `selftest-log`) буде рядок `[ПРОВАЛ] …` з назвою модуля, якого бракує в пакеті.
- **«Інсталятор»** – не критично, основна збірка (zip) однаково буде готова.
Надішліть мені вивід червоного кроку – за ним зазвичай видно причину.

## Корисно знати
- Файл карти світу `sad_worldmap.npz` (≈ 8 МБ, дані Natural Earth) лежить у корені репозиторію разом із програмою й автоматично потрапляє в збірку. Без нього кнопка «Обрати на карті» повідомить про відсутність карти; тоді місце можна знайти за назвою (пошук тоді йде через інтернет) або ввести координати вручну кнопкою «Ввести координати…».
- Розмір програми ≈ 200–250 МБ (scipy, matplotlib, numpy). Режим «один файл» не використано: він повільно стартує й частіше викликає хибні спрацювання антивірусів.
- Перевірити зібрану програму вручну: `SAD.exe --selftest --selftest-out log.txt`.
- Статистика використання зберігається у `%APPDATA%\\SAD\\usage.json`, налаштування діаграм погоди – у `%APPDATA%\\SAD\\weather_chart_style.json`. Кешу погоди немає: дані завантажуються щоразу заново.
