S.A.D. v2.1 — Статистичний аналіз даних (агрономічні дослідження, селекція)
================================================================================

ЗАПУСК
    pip install -r requirements.txt
    python main.py
(на Linux, якщо немає tkinter:  sudo apt install python3-tk)

РОЗДІЛИ ПРОГРАМИ (головна сторінка, зліва)
    Польовий журнал ........ Польовий журнал обліків (внесення даних у схему досліду, серії повторних вимірів)
    Погода ................. NASA POWER · Open-Meteo (ERA5) · власні дані; ГТК, САТ/СЕТ, кліматограми, діаграма
                             Вальтера, норма й відхилення; експорт Excel/Word/CSV, текст методики
    ANOVA .................. однофакторний (CRD, RCBD, ЛК), двофакторний (CRD, RCBD, split-plot),
                             трифакторний (латинський квадрат), чотирифакторний
    Базові методи .......... описова статистика; t-тест / Манна–Уітні
    Зв'язок змінних ........ кореляційний аналіз (Пірсон, Спірмен, Кендалл τ-b; довірчі інтервали; поправки Холма,
                             Бонферроні, Беньяміні–Хохберга; таблиця пар; частинна й напівчастинна кореляція);
                             генотипні й фенотипні кореляції rG, rP, rE (бутстреп-інтервали);
                             зв'язок змінних різних типів (η, рангово- й точково-бісеріальний, V Крамера, таблиці спряженості);
                             регресійний аналіз; ANCOVA
    Багатовимірні .......... MANOVA; повторні виміри; змішаний RM (split-plot у часі)
    Багатовимірний ML ...... кластерний аналіз; PCA
    Планування досліду ..... конструктор схеми досліду (за рослинами чи за площею);
                             схеми для багатьох номерів (альфа-решітка, аугментована за Федерером)
    Селекція та генетика ... аналіз стабільності (G×E: AMMI, GGE, Еберхарт–Рассел, 20+ індексів);
                             порівняння зі стандартом (Дуннетт); змішана модель REML/BLUP;
                             індекси добору (Сміт–Хейзел, базовий, Песек–Бейкер); гетерозис гібридів F₁;
                             бальні ознаки й AUDPC; генетичні параметри; комбінаційна здатність
                             (лінія × тестер, діалель за Гріффінгом); стресостійкість; шляховий аналіз

ПОГОДНІ ДАНІ: ВАЖЛИВО
    • NASA POWER: безкоштовно; у публікаціях зазначайте подяку (додається до експорту автоматично).
    • Open-Meteo: безкоштовний доступ лише для НЕКОМЕРЦІЙНОГО використання. Якщо S.A.D. поширюється за підпискою
      чи комерційно — потрібна платна підписка Open-Meteo. Для комерційного поширення безпечніше NASA POWER.
    • Це реаналіз для комірки сітки, а не вимірювання на ділянці; для дисертації бажано порівняти з найближчою станцією.
    • Завантажені дані кешуються в теці ~/.sad_weather_cache.

ОБМЕЖЕННЯ Й ЧЕСНА ІНФОРМАЦІЯ ПРО ПЕРЕВІРКУ
    • Усі розрахунки перевірено на синтетичних і побудованих даних та проти незалежних еталонів (scipy, таблиці
      Дуннетта, аналітичні формули, симуляції). На реальних завершених дослідах програму ще не випробувано —
      перед використанням у публікаціях звірте кілька власних аналізів з іншим пакетом.
    • Мережеве з'єднання з серверами NASA POWER та Open-Meteo не перевірялось у середовищі розробки (сервери
      були недоступні); розбір відповідей і обробка помилок перевірені на зразках за документованим форматом.
      Перший реальний запит варто зробити й переконатися, що дані завантажуються.
    • Аналізи стабільності, AMMI та комбінаційної здатності потребують повних таблиць (без пропусків);
      для незбалансованих даних використовуйте змішані моделі.
    • Погода як коваріата в ANCOVA свідомо не реалізована: річна погода однакова для всіх ділянок року
      (змішується з ефектом «рік»), а спостереження на тих самих ділянках у різні роки залежні.
